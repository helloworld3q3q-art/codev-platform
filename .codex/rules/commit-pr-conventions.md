# Commit / PR 红线（项目独有）

> Conventional commits 通识（type/scope/常规 PR 模板）按业界标准做即可，本文件只列项目独有的红线。

## 🚨 commit message 红线（HIGHEST PRIORITY）

**提交信息必须使用中文表达变更内容**：

- `type(scope):` 可按 Conventional Commit 保留英文，例如 `chore(codex): 迁移项目智能体配置`
- `subject` 必须是中文，不能写成纯英文，例如禁止 `migrate project agent config`
- commit body / PR title / PR body 也优先使用中文；引用命令、路径、接口名、英文专有名词除外
- 用户没有指定 message 时，Codex 必须自动生成中文 subject；没把握就先问，不要提交英文 subject

**禁止在 commit message / PR 描述中出现任何 AI 工具痕迹**：

```
❌ Co-Authored-By: Claude <noreply@anthropic.com>
❌ Co-Authored-By: Claude Opus 4.x ...
❌ 🤖 Generated with [Claude Code](https://claude.com/claude-code)
❌ Generated by GitHub Copilot
❌ AI-assisted commit
❌ 任何模型名 / 工具名 / noreply@anthropic.com 邮箱后缀
```

**适用范围**：commit message、merge commit、PR title、PR body、commit body 任何位置。

**原因**：
- 仓库是个人/团队作品，commit 历史是人类工程师署名
- 留 AI 痕迹会让 `git log` / `git blame` 不专业，且不利于商业化
- 协作者本就清楚 AI 参与编码，不需要在每条 commit 反复声明

**操作准则**：
- AI 自动加的 `Co-Authored-By` / 🤖 generator 标识，**写 commit 前必须删掉**
- 已 commit 历史里有 AI 痕迹 → 未推送时立刻 `git commit --amend` 修正；已推送的不强求改写
- PR template 不写 "Generated with Claude" 之类内容

**自检**：

```powershell
git log --pretty=%B -10 | Select-String -Pattern "claude|copilot|noreply@anthropic|🤖 Generated" -CaseSensitive:$false
```

输出应为空。最近一条提交的 `subject` 应包含中文变更描述。
