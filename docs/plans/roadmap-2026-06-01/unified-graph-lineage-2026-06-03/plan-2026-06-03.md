# Plan:统一图谱·全栈血缘收敛 (2026-06-03)

> 方案见 [`design-2026-06-03.md`](design-2026-06-03.md)。四期独立可交付,parity 门控,openclaw 全程不空。

## P1 — Spring 端点插件(Java 后端节点)

**目标**:`@RestController` / `@RequestMapping` / `@(Get|Post|Put|Delete|Patch)Mapping` → `backend_endpoint` 节点(language=java)。镜像 fastapi 插件,零项目绑定。

| 步骤 | 文件 | 验证 |
|---|---|---|
| `_stack_scan.spring_detect / scan_spring`(正则扫 .java 注解,class 级 base path + method 级拼接 url) | `plugins/builtin/_stack_scan.py` | 单测:openclaw apps/*-api 扫出端点 |
| `SpringPlugin(AnalyzerPlugin)`(detect/analyze 调上面) | `plugins/builtin/backend_spring.py` | `registry.list_plugins()` 含 `builtin.backend_spring`(自动发现) |
| node id 与 fastapi 同构 `<pid>:backend_endpoint:<METHOD>:<url>` | — | 同 url 跨 java/py 可被 linker 命中 |

**测试**:`tests/test_plugin_backend_spring.py`(detect 命中 / url 拼接 / method / id 形态)。
**验收**:`pytest tests/test_plugin_backend_spring.py` 全过;openclaw ingest 后 store 出现 java `backend_endpoint`。

## P2 — sql 插件扩 DML(上游→表→后端)

**目标**:扫 INSERT/UPSERT/UPDATE/SELECT + 所在函数 → `backend_function`(role=writer/reader)节点 + `writes_table` / `reads_table` 边。

| 步骤 | 文件 | 验证 |
|---|---|---|
| Python DML 扫描(`cursor.execute` 字面量 + 常见 ORM 写读)解析目标表 + 归属函数 | `plugins/builtin/sql.py` | 单测:INSERT→writes / SELECT→reads |
| 表名 lower 命中已建 `db_table` id;函数节点 `<pid>:backend_function:<file>:<func>` | `plugins/builtin/sql.py` | 边端点都落在已存在节点 |
| endpoint↔reader 同文件弱 `calls` 边(启发,confidence<1) | `plugins/builtin/sql.py` 或 linker | 可选,标 evidence |

**测试**:`tests/test_plugin_sql_dml.py`。
**验收**:codev / openclaw ingest 后 store 出现 `writes_table` / `reads_table` 边,表能上溯写库函数。

## P3 — 核心 linker pass 接进 ingest

**目标**:`ingest_project` 末尾加跨插件 linker,产 `calls_api`(前端→后端)边,挂 `builtin.linker`。

| 步骤 | 文件 | 验证 |
|---|---|---|
| ingest 各插件 upsert 后,从 store 读全量节点 → `_stack_scan.link_api_calls(...)` | `graph/ingest.py` | 复用已有函数,不重写 |
| 结果以 `AnalyzerResult(plugin="builtin.linker")` upsert(幂等) | `graph/ingest.py` | 重跑不重复 |

**测试**:`tests/test_ingest_linker.py`(前端 api_call + 后端 endpoint 同 url → 产 calls_api)。
**验收**:openclaw ingest 后 `calls_api` 边数 > 0(此前 fastapi edges=0)。

## P4 — parity 达标 → 删 cross_link + 并页 + 防复发

| 步骤 | 文件 | 验证 |
|---|---|---|
| parity 工具:`stack+linker` 的 endpoint 数 / calls_api 连通 ≥ cross_link 现覆盖 | `tools/audit_graph_parity.py`(新) | 跑 openclaw 输出对账表 |
| 达标 → 删 cross_link 适配器 + 注册;cross-link 路由/页面并入统一图谱 | `graph/adapters/cross_link.py` / `web/routes/graph.py` / web-ui | 全量 pytest 不降 |
| 防复发:`kind×语言→owner` 注册 + 约定测试(同 `(kind,name,file)` 不跨插件重复) | `plugins/registry.py` / `tests/test_plugin_owner_uniqueness.py` | 故意造重复 → 测试红 |

**验收**:删 cross_link 后 openclaw 统一图谱节点/边不少于删前的 stack+linker 部分;parity 工具绿;防复发测试绿。

## 执行顺序

P1 → P2 → P3 可并行起头(互不阻塞),P4 必须等 P1–P3 全绿 + parity 达标。本轮先交付 **P1**。

## 验证基线

每期:`pytest tests/`(数不下降)+ 改动文件 eslint(若含前端)。后端契约改动 → commit/push/WSL 重启 `codev-web`。
